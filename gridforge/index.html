GridForge

Edit a grid, use basic arithmetic formulas, and import/export CSV.

Enter values or simple formulas like =A2+B2 or =A2*B2. Formulas support basic arithmetic.

Local prototype: Data stays in this browser where implemented. No cloud sync, user accounts, or shared backend. Export backups regularly.
