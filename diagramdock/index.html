DiagramDock

Build a simple diagram with movable boxes and circles, connectors, and SVG export.

Select a shape; drag to move it. Select Connect, then click another shape. Rename changes the selected shape label.

Local prototype: Data stays in this browser where implemented. No cloud sync, user accounts, or shared backend. Export backups regularly.
